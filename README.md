# Fit & Predict — Учебник машинного обучения

Интерактивный учебник по ML в стилистике Fit & Predict. В нём есть сценарий знакомства, спиральная карта из шести модулей, профиль и настоящие интерактивные алгоритмы: KNN, линейная и логистическая регрессии, решающее дерево, SVM и многослойный перцептрон (MLP).

У каждого алгоритма есть отдельная длинная страница теории с левым оглавлением, формулами, визуальными схемами и ссылками на русскоязычные материалы. Лаборатории позволяют исследовать обучение моделей, параметры и датасеты, а отдельный экран профайлинга показывает распределения, статистики и корреляции признаков.

Глава линейной регрессии включает 37 разделов: вывод коэффициентов через производные и ковариацию, матричные дифференциалы, проекции и SVD, сходимость градиентного спуска, разные распределения шума, доказательство теоремы Гаусса–Маркова, доверительные и предиктивные интервалы, GLS, ridge/lasso и байесовский вывод. Доказательства сопровождаются условиями применимости, числовым примером и ссылками на Хабр, Яндекс Учебник и материалы НИУ ВШЭ.

```bash
docker compose up --build
```

Откройте `http://localhost:8080` или привычный `http://localhost:4173`.

python3 -m http.server 4173 --bind 127.0.0.1

Откройте `http://localhost:4173`.

## Пользовательские сценарии

```bash
npm install
npx playwright install chromium
npm test
```

Тесты проверяют сценарии первого входа, обучение демонстрационной модели, регистрацию и пропуск регистрации, профиль с фото, карту из шести модулей, профайлинг датасетов и интерактивность всех алгоритмов. Для MLP дополнительно проверяются реальные градиенты, все схемы инициализации, ручное изменение параметров, остановка при навигации, воспроизводимость, математика Markdown, мобильный экран и ресурсы после повторных заходов.

Математические проверки (`npm run test:math`) сверяют числовой пример главы, реальные градиенты с конечными разностями, моменты оценок на всех реализациях небольшого негауссовского шума, масштаб регуляризации и условие на learning rate. Это численная проверка примеров и связи текста с алгоритмом; сами доказательства приведены в главе.

## PDF по линейной регрессии

Готовый документ находится в `output/pdf/fitpredict-linear-regression.pdf`. Рядом лежит редактируемый офлайн-исходник `fitpredict-linear-regression.html`: текст в HTML, формулы в TeX внутри элементов `source-equation`. Для редактирования исходника не нужен интернет; MathJax встроен с лицензией. После открытия изменённого HTML его можно распечатать в PDF через браузер. Другие алгоритмы в этот документ не входят; MLP не изменяет существующую сборку PDF.

Для воспроизводимой сборки из текущей теории сайта:

```bash
npm install
npx playwright install chromium
npm run build:pdf
```

Текст берётся из `src/linear-theory.js`, а не из отдельной копии главы. `scripts/math-typesetting.mjs` задаёт TeX-эквиваленты формул. Сборщик проверяет все разделы, сохранность абзацев, ссылки оглавления, ошибки в формулах и горизонтальное переполнение. `theory-manifest.json` записывает хеш исходного содержимого и перечень разделов. При изменении формулы сайта сборка останавливается: сначала нужно сверить TeX и обновить соответствующий SHA-256 от JSON-массива исходных формул в `scripts/theory-equation-hashes.json`. Актуальный массив создаёт `node scripts/build-theory-pdf.mjs --inventory` в `tmp/pdfs/equations.json`.

После сборки страницы дополнительно проверяются визуально. Для проверки полного состава PDF и подготовки контактных листов нужны Python-пакеты `pypdf`, `pdfplumber`, `Pillow` и Poppler:

```bash
pdftoppm -jpeg -r 45 output/pdf/fitpredict-linear-regression.pdf tmp/pdfs/linear-preview
python3 scripts/verify-theory-pdf.py
```

Численные тесты не заменяют чтение доказательств, а проверки PDF - визуальную проверку формул и переносов.

## Лаборатория MLP

Выберите шестую вершину карты и нажмите «Открыть». Маршруты `mlp` и `mlp-theory` используют существующее переключение экранов. Изначально выбран воспроизводимый XOR: сеть 2 → 8 → 8 → 1, tanh, Xavier normal, η = 0.08, батч 32, λ = 0.0001; seeds данных / весов / порядка: 42 / 7 / 19.

- Архитектура: 1–4 скрытых слоя, 1–16 нейронов в каждом; ReLU, tanh или сигмоида. Последний слой автоматически выбирает сигмоиду для бинарной классификации и линейный выход для регрессии.
- Данные: XOR, концентрические окружности и нелинейная волна; 128 обучающих и 64 проверочных объекта. Статистики нормализации оцениваются только по обучающей части. Профайлинг показывает исходные признаки и таргет.
- «Инициализировать» применяет архитектуру, распределение и seeds, создаёт новые параметры и очищает историю. Доступны нулевые веса, собственные uniform и normal, нормальные и равномерные Xavier и He. Смещения задаются отдельно, по умолчанию 0.
- «Прямой проход» и «Обратный проход» анимируют расчёт выбранного примера при текущих весах. «Один шаг» выполняет настоящее обновление по следующему батчу; анимационные фазы и шаг SGD не смешиваются.
- «Обучать» запускает непрерывный SGD, «Пауза» останавливает его. «Сбросить» восстанавливает исходные параметры и порядок батчей, обнуляет шаги и историю; текущие настройки η, размера батча и λ остаются выбранными.
- Нейроны, связи и смещения доступны мышью и через Tab / Enter. Карточка нейрона показывает входные вклады, z, a, производную активации и δ. Карточка параметра позволяет изменить его на паузе и показывает отдельно индивидуальный градиент и фактически применённый градиент прошлого батча.
- Фильтр связей помогает изучать большие сети. Цвета объяснены в легенде. На поле предсказаний обучающие точки — круги, проверочные — ромбы. Уважено системное предпочтение reduced motion.
- Паспорт инициализации показывает точное распределение, fan-in/out, теоретическую дисперсию, фактические среднее и дисперсию и гистограммы. Сравнения стартов сохраняют до четырёх кратких результатов в памяти вкладки; таблица отображает только запуски с совпадающими остальными настройками.

### Математические соглашения

Векторы одного объекта — столбцы. W слоя имеет форму `[выходы, входы]`; батч состоит из столбцов. Регрессионная потеря — половина квадрата ошибки; BCE вычисляется устойчиво по логиту. Цель батча: средняя потеря + λ/2 × сумма квадратов всех весов. Поэтому штраф добавляет λW, смещения не штрафуются. Усреднение градиентов происходит ровно один раз. Для ReLU в нуле выбрана производная 0.

На графиках показана ошибка данных без L2. Для регрессии RMSE = sqrt(2 × loss). Последнее обновление хранит параметры **до** шага, фактический средний градиент, η, λ и состав батча. Текущие активации и метрики заново вычисляются после обновления; все текущие панели обозначены одним номером шага и версии. Малый индивидуальный градиент не выдаётся за доказательство сходимости.

Авторитетный исходник главы — `src/mlp-theory.md`: 29 разделов, 451 отрисованное математическое выражение, предпосылки, выводы, численный пример, упражнения с раскрываемыми решениями и проверенные первичные источники. Формулы записаны стандартным TeX внутри `$...$` и `$$...$$`. Marked 15.0.12 (MIT) и имеющийся MathJax 3.2.2 загружаются локально только при открытии главы; CDN во время работы не нужен. HTML фильтруется по разрешённым элементам и атрибутам. Формулы, матрицы и длинные выводы прокручиваются внутри своих блоков. Оглавление не запускает повторную обработку формул.

### Структура реализации и сохранение

`src/mlp/core.js` содержит численное ядро и Experiment, `config.js` — небольшой валидируемый конфиг и PRNG, `data.js` — синтетические данные, `diagram.js` — доступную SVG-сеть, `plots.js` — Canvas-графики, `lab.js` — жизненный цикл и управление, `view.js` — разметку, `theory-loader.js` — безопасный ленивый Markdown/TeX. Стили изолированы в `styles/mlp.css`.

Численные параметры, градиенты, история и рабочие буферы не входят в общий store и не сериализуются при SGD. В `fitpredict-ml-textbook-v6` сохраняются только настройки MLP с версией схемы 1. Неизвестные поля и несовместимые, повреждённые или чрезмерные настройки отбрасываются без потери корректного профиля. При недоступном или заполненном localStorage приложение продолжает работать в текущей вкладке.

Переход к теории, карте или профайлингу останавливает обучение и сохраняет текущую сеть в памяти вкладки. Перезагрузка воспроизводит начальный эксперимент по сохранённым настройкам; текущие обученные веса не восстанавливаются. При выходе освобождаются обработчики и кадры; поздняя загрузка главы не может заменить уже открытый другой экран.

### Производительность и измерения

В численных циклах переиспользуются Float64Array. Хранится один предыдущий набор параметров для объяснения обновления, а не снимок каждой итерации. История ограничена 240 точками с прореживанием старых значений; поле вероятностей использует фиксированные буферы 80 × 60. Геометрия SVG строится при создании сети, затем обновляются существующие элементы. Обучение работает порциями до 6 мс и до 40 шагов за кадр; визуализация обновляется не чаще примерно 12 раз/с. Для текущих ограничений Worker не понадобился.

Локальный замер в Chromium headless, 9 ноября 2026 года: 128 обучающих / 64 проверочных объекта, батч 32. Перед замером чистого ядра выполнено 50 разогревающих шагов, затем 500 измеряемых. Обновление визуализации измерено на 20 кадрах после трёх разогревающих.

| Архитектура | Параметров | Чистое ядро, шагов/с | Обновление визуализации, медиана / p95 | Численные буферы Experiment |
| :--- | ---: | ---: | ---: | ---: |
| 2 → 8 → 8 → 1 | 105 | около 73 500 | 1.1 / 1.4 мс | 6 872 байта |
| 2 → 16 → 16 → 16 → 16 → 1 | 881 | около 13 200 | 4.6 / 4.8 мс | 47 576 байт |

Частота чистого ядра не является частотой анимации. Стоимость визуализации включает расчёт поля, подготовку графиков и изменения DOM, но не последующую растеризацию браузером. К буферам Experiment добавляются примерно 57 КиБ фиксированных буферов поля, данные, ограниченная история, DOM и ресурсы браузера. Это наблюдения этой машины, а не гарантия для всех устройств.

После восьми повторных переходов и инициализаций число обработчиков не изменилось; рост DOM соответствовал одной добавленной строке таблицы сравнения, активных кадров после остановки — ноль. Измерение выполняется после сборки мусора; небольшие колебания JS heap не интерпретируются как точный размер модели. Тесты освобождают собственные ElementHandle перед замерами.

### Проверка MLP

```bash
npm run test:mlp
npm run test:math
npm test
```

`tests/mlp-math.mjs` сверяет независимый скалярный расчёт, все опубликованные числа примера (включая видимую таблицу), центральные разности весов, смещений и входов, производные активаций, экстремальные логиты, усреднение и L2, масштабы начальных распределений, симметрию, частичный батч, отклонение нестабильного шага и восстановление настроек. На seeds по умолчанию после 2000 шагов XOR и окружности дают 100% проверки; RMSE волны примерно 0.1003. Это результаты фиксированных примеров, не универсальная гарантия.

`tests/mlp-browser.mjs` сохраняет скриншоты и фактические измерения в `tmp/mlp-qa/`, включая `performance.json`. Этот каталог не коммитится. Существующие `tests/user-flows.mjs` продолжают проверять прежние алгоритмы и дополнены шестой вершиной карты.

Ограничения: один выход, SGD без Momentum/Adam, ручная ранняя остановка, до четырёх скрытых слоёв и 16 нейронов в каждом. Softmax и адаптивные оптимизаторы объяснены в теории как расширения. Нет автоматического сертификата сходимости, сохранения обученных весов между перезагрузками и PDF для MLP.
