# Fit & Predict — Учебник машинного обучения

Интерактивный учебник по ML в стилистике Fit & Predict. В нём есть сценарий знакомства, спиральная карта из шести модулей, профиль и настоящие интерактивные алгоритмы: KNN, линейная и логистическая регрессии, решающее дерево, SVM и многослойный перцептрон (MLP).

Первые пять алгоритмов имеют лаборатории обучения, страницы теории и профайлинг данных. MLP — вводный урок про архитектуру, прямое вычисление и роль нелинейности; его объяснение находится сразу под схемой сети.

Глава линейной регрессии включает 37 разделов: вывод коэффициентов через производные и ковариацию, матричные дифференциалы, проекции и SVD, сходимость градиентного спуска, разные распределения шума, доказательство теоремы Гаусса–Маркова, доверительные и предиктивные интервалы, GLS, ridge/lasso и байесовский вывод. Доказательства сопровождаются условиями применимости, числовым примером и ссылками на Хабр, Яндекс Учебник и материалы НИУ ВШЭ.

## Запуск в Docker

```bash
docker compose up --build
```

Откройте `http://localhost:8080` или привычный `http://localhost:4173`.

## Локальная разработка

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://localhost:4173`.

## Пользовательские сценарии

```bash
npm install
npx playwright install chromium
npm test
```

Тесты проверяют сценарии первого входа, обучение демонстрационной модели, регистрацию и пропуск регистрации, профиль с фото, карту из шести модулей, профайлинг датасетов и интерактивность всех алгоритмов. Для MLP проверяются четыре точных примера XOR, промежуточные значения, архитектура, переключение активации без изменения весов, сброс, клавиатура, формулы, мобильный экран и очистка ресурсов.

Математические проверки (`npm run test:math`) сверяют числовой пример главы, реальные градиенты с конечными разностями, моменты оценок на всех реализациях небольшого негауссовского шума, масштаб регуляризации и условие на learning rate. Это численная проверка примеров и связи текста с алгоритмом; сами доказательства приведены в главе.

## PDF по линейной регрессии

Готовый документ находится в `output/pdf/fitpredict-linear-regression.pdf`. Рядом лежит редактируемый офлайн-исходник `fitpredict-linear-regression.html`: текст в HTML, формулы в TeX внутри элементов `source-equation`. Для редактирования исходника не нужен интернет; MathJax встроен с лицензией. После открытия изменённого HTML его можно распечатать в PDF через браузер. Другие алгоритмы в этот документ не входят; MLP не изменяет существующую сборку PDF.

Для воспроизводимой сборки из текущей теории сайта:

```bash
npm install
npx playwright install chromium
npm run build:pdf
```

Текст берётся из `src/linear-theory.js`, а не из отдельной копии главы. `scripts/math-typesetting.mjs` задаёт TeX-эквиваленты формул. Сборщик проверяет все разделы, сохранность абзацев, ссылки оглавления, ошибки в формулах и горизонтальное переполнение. `theory-manifest.json` записывает хеш исходного содержимого и перечень разделов. При изменении формулы сайта сборка останавливается: сначала нужно сверить TeX и обновить соответствующий SHA-256 от JSON-массива исходных формул в `scripts/theory-equation-hashes.json`. Актуальный массив создаёт `node scripts/build-theory-pdf.mjs --inventory` в `tmp/pdfs/equations.json`.

После сборки страницы дополнительно проверяются визуально. Для проверки полного состава PDF и подготовки контактных листов нужны Python-пакеты `pypdf`, `pdfplumber`, `Pillow` и Poppler:

```bash
pdftoppm -jpeg -r 45 output/pdf/fitpredict-linear-regression.pdf tmp/pdfs/linear-preview
python3 scripts/verify-theory-pdf.py
```

Численные тесты не заменяют чтение доказательств, а проверки PDF - визуальную проверку формул и переносов.

## Вводный урок MLP

Выберите шестую вершину карты и нажмите «Открыть». Урок посвящён трём вопросам: из чего состоит сеть, как сигнал проходит через слои и почему нужна нелинейность.

- Четыре фиксированных входа XOR: (0,0), (0,1), (1,0), (1,1). Выбор примера пересчитывает настоящие суммы и активации без изменения коэффициентов.
- Эталонная сеть 2 → 2 → 1: первая матрица [[1,-1],[-1,1]], выходные веса [1,1], все смещения нулевые. Скрытая ReLU даёт |x₁−x₂| и ответы 0,1,1,0. Выход линейный: это значение функции, а не вероятность.
- Тождественная скрытая активация при тех же параметрах даёт ноль. Переключение активации сохраняет массив весов.
- Архитектура: 0–2 скрытых слоя, 1–4 нейрона в каждом. Другие схемы получают документированные фиксированные коэффициенты; произвольная схема не обязана решать XOR.
- Нейрон раскрывает входы, веса, произведения, смещение, сумму z и активацию a. Связь показывает один вклад, b — роль смещения. Элементы доступны через Tab, Enter и пробел.
- «Прямой проход» кратко подсвечивает слои. Обычный выбор и изменение архитектуры работают сразу. Reduced motion отключает анимацию.
- Возврат к примеру восстанавливает точные коэффициенты сети 2 → 2 → 1, ReLU и вход (0,1).

Сеть не обучается в фоне. Управления обучением, сравнений стартов, случайных выборок, профайлинга MLP и диагностических панелей в этом уроке нет.

### Фиксированные коэффициенты

Без скрытых слоёв выход равен x₁−x₂. Первый скрытый слой берёт первые строки списка [[1,-1],[-1,1],[1,1],[-1,-1]]. Второй скрытый слой, если есть, содержит единицы на доступной диагонали и нули вне неё. Все выходные веса равны 1, все смещения — 0. Изменение архитектуры строит сеть по этому правилу; изменение только активации сохраняет коэффициенты.

### Теория и устройство кода

Авторитетный источник — `src/mlp-theory.md`. Он объясняет нейрон, размеры матриц, композицию, подсчёт параметров, аффинные отображения, невозможность линейного разделения XOR и явную конструкцию с ReLU. Видимая таблица полного прямого прохода проверяется численно.

Формулы `$...$` / `$$...$$` оформляются локальными Marked (MIT) и MathJax. Зависимости подгружаются, когда читатель приближается к объяснению или нажимает ссылку. Маршрут `mlp-theory` открывает тот же материал с возвратом к сети. Выбор примера не запускает повторное оформление формул. Широкие таблицы и выражения прокручиваются локально.

`lesson.js` задаёт коэффициенты и буферы только прямого прохода; `data.js` содержит четыре наблюдения. `core.js` сохраняет переиспользуемые численные функции с проверками, но урок вызывает только создание модели и прямое вычисление. Старый класс обучения и графики удалены. `lab.js` управляет взаимодействием и очисткой ресурсов, `diagram.js` — схемой и одной карточкой разбора, `view.js` — разметкой, `theory-loader.js` — безопасным Markdown и математикой.

Геометрия пересоздаётся только при изменении архитектуры или возврате к примеру. Выбор входа, элемента и активации обновляет существующие узлы. Единственная анимация ограничена длительностью прямого прохода; при новом выборе или уходе она отменяется. Обработчики и наблюдатель чтения освобождаются при выходе.

В localStorage сохраняются настройки схемы версии 2: скрытые слои, активация и выбранный вход. Старые настройки полной лаборатории заменяются исходным примером. Старый маршрут профайлинга MLP направляется к уроку; профиль пользователя и состояние других алгоритмов сохраняются.

### Проверка

`npm run test:mlp` запускает численные и браузерные проверки. `npm test` дополнительно проверяет линейную регрессию и прежние пользовательские сценарии.

Численные тесты проверяют коэффициенты, четыре строки XOR с промежуточными значениями, тождественную активацию, другие допустимые схемы и миграцию настроек. Сохранены проверки переиспользуемых функций ядра, включая конечные разности и устойчивость вычислений.

Браузерные тесты проверяют выбор примера, нейрона, связи и смещения, настройки, сброс, отсутствие фонового обучения, сохранение DOM, навигацию, загрузку и ошибки формул, клавиатуру и мобильный экран. Во время этих тестов обращения урока к функциям обучения вызывают ошибку. Артефакты сохраняются в игнорируемый каталог `tmp/mlp-intro-qa/`.

Урок работает с одним числовым выходом и четырьмя наблюдениями XOR. Другие сценарии и обучение сети выходят за рамки этой вводной версии. Существующий PDF по линейной регрессии сохраняется.
